Deploy on Vercel (static site, no build step)
1. Unzip this folder.
2. Option A: vercel.com > Add New > Project > drag and drop the folder (or push to GitHub and import).
   Option B: run `npx vercel --prod` inside the folder.
3. Framework Preset: Other. Build Command: empty. Output Directory: leave default (root).
To add photos/music later: put files next to index.html and reference them by relative path.
